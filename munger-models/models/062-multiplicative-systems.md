# 乘法系统思维

Multiplicative Systems

当成功要求每个环节都成功时，总成功率是各环节概率的乘积，衰减速度远超直觉预期。

2003年2月1日，哥伦比亚号航天飞机在返回大气层时解体，七名宇航员全部遇难。直接原因是一块手提箱大小的隔热泡沫脱落，撞击左翼，砸出了一个洞。

一块泡沫。一个洞。七条生命。

航天飞机有超过250万个零部件。任何一个零部件的失效都可能导致灾难性后果。即使每个零部件的可靠性都达到了99.99%，当250万个99.99%串联在一起时，整个系统的可靠性被乘法法则无情地拉低。

## 乘法的残酷算术

假设你有一个计划，需要五个独立的步骤全部成功才能实现目标。每一步成功的概率都很高——80%。

但乘法告诉你：0.8 x 0.8 x 0.8 x 0.8 x 0.8 = 0.328

总成功率只有33%。五个"很可能成功"的环节串在一起，整体上变成了"很可能失败"。

即使每步成功率高达95%：0.95^10 = 0.599。成功率还是只有60%。

## 航天飞机：乘法的极致教训

费曼在挑战者号灾难后，直接去找一线工程师，问他们认为航天飞机发射失败的概率是多少。

工程师们的估计大约是1/100。NASA管理层给出的官方数字呢？1/100,000。

差了三个数量级。

## 芒格的选择

芒格偏好"简单确定"投资的数学基础是：**当芒格投资可口可乐时，他的"商业计划"只有极少的必要环节。**

四个高确定性环节串联：0.95 x 0.95 x 0.95 x 0.90 = 0.77。

和一个需要七个步骤的创业计划相比，芒格的方法在数学上是碾压性的优势。不是因为他每一步做得更好，而是因为他需要做对的步骤更少。

## 芒格原话

"我们不是通过更聪明地解决困难问题来赚钱的。我们是通过避开困难问题来赚钱的。"

"We don't try to make money by being smarter at difficult problems. We try to make money by avoiding difficult problems."
